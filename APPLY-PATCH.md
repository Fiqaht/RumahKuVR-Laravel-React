# RumahKuVR Professional Device Patch v4

This patch removes the rough procedural 3D headset/controller models and replaces them with a professional, image-led device showcase inspired by the supplied editorial card reference.

Included real licensed hardware photos:
- Meta Quest 3 — CC BY-SA 4.0
- DualShock 4 — Public Domain
- Xbox One controller — Public Domain

The Three.js hero scene remains. Device cards use subtle CSS perspective/hover depth instead of fake hardware geometry.

Apply by merging `resources/`, `public/`, and `package.json` into the current Laravel project, then run `npm install` and `npm run dev`.
